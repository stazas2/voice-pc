# Voice PC Cloud Functions

Модульная система для развертывания голосового управления ПК через Yandex Alice в облаке.

## 🏗️ Архитектура

```
cloud/
├── index.js                   # Главная функция (точка входа)
├── 📁 core/                    # Основные компоненты
│   ├── api-client.js          # HTTP клиент для отправки команд
│   └── response-generator.js  # Генерация ответов для Алисы
├── 📁 parsers/                # Парсинг и обработка команд
│   ├── command-parser.js      # Базовый парсер команд
│   ├── smart-parser.js        # Умный парсер с фаззи-поиском
│   ├── fuzzy-matcher.js       # Нечеткое сопоставление команд
│   └── context-memory.js      # Память контекста диалога
├── 📁 config/                 # Конфигурация и команды
│   ├── config.js              # Настройки URL и токенов
│   └── command-mappings.js    # Маппинг голосовых команд
├── 📁 utils/                  # Вспомогательные утилиты
│   └── (готов для расширения)
└── 📁 docs/                   # Документация
    ├── README.md              # Этот файл
    └── DEPLOY.md              # Инструкция по развертыванию
```

## 🚀 Быстрый старт

### 1. Точка входа
- **Функция**: `index.handler`
- **Среда выполнения**: Node.js 18
- **Память**: 128 МБ (рекомендуемо)

### 2. Развертывание
```bash
# Скопировать все файлы в Yandex Cloud Function
# Установить точку входа: index.handler
# Настроить переменные окружения в config/config.js
```

### 3. Настройка
Отредактируйте `config/config.js`:
```javascript
const config = {
    serverUrl: 'https://ваш-домен.com',
    apiEndpoint: '/command',
    timeout: 5000
};
```

## ⚙️ Компоненты системы

### Core (Ядро)
- **index.js** - Главная функция обработки запросов от Алисы (точка входа)
- **core/api-client.js** - Отправка команд на локальный ПК через HTTP
- **core/response-generator.js** - Формирование ответов пользователю

### Parsers (Парсеры)
- **smart-parser.js** - Продвинутый парсер с поддержкой:
  - 🎯 Нечеткий поиск (fuzzy matching)
  - 🧠 Память контекста диалога
  - 🔢 Парсинг чисел в командах
  - 📊 Приоритизация результатов
- **fuzzy-matcher.js** - Алгоритм нечеткого сопоставления
- **context-memory.js** - Управление контекстом сессии

### Config (Конфигурация)
- **config.js** - Центральная конфигурация системы
- **command-mappings.js** - Более 150+ голосовых команд

## 🎛️ Поддерживаемые команды

### Категории команд:
- 🗣️ **Активация навыка** - запуск и приветствие
- 📝 **Приложения** - блокнот, калькулятор, браузер
- 🌐 **Веб-сайты** - YouTube, Google, GitHub, ChatGPT
- ⚡ **Система** - выключение, сон, блокировка
- 🎵 **Медиа** - управление воспроизведением, громкость
- 📁 **Файлы** - открытие папок, последние загрузки
- 🖥️ **Windows API** - управление окнами (Edge.js)
- 🔊 **Точная громкость** - установка конкретных значений
- 📷 **Скриншоты** - захват экрана и запись

### Примеры команд:
```
"Алиса, запусти навык головной отрыв"
"открой ютуб"
"громкость компьютера пятьдесят" 
"закрой хром"
"разверни блокнот"
"сделай скрин"
```

## 🔧 Расширение системы

### Добавление новых команд:
1. Отредактируйте `config/command-mappings.js`
2. Добавьте обработку в `core/response-generator.js`
3. Протестируйте через веб-дашборд

### Добавление новых парсеров:
1. Создайте файл в `parsers/`
2. Интегрируйте в `index.js`
3. Обновите документацию
