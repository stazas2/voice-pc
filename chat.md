# План улучшений

## 1. Хранение секретов и конфигураций
- Перенести `WEBHOOK_URL`, `ALICE_TOKEN` и API-ключи в переменные окружения функции.
- Использовать Yandex Lockbox или другой секрет-менеджер.
- Регулярно ротировать ключи, ограничивать права (только на нужные действия).

## 2. Структура и сборка функции
- Разбить `cloud/` на модули: маппинги, парсеры, HTTP-клиент.
- Собирать единый бандл через `esbuild`/`tsup` для снижения cold-start.
- Минимизировать зависимости, выбирать лёгкие пакеты.

## 3. Безопасность и контроль доступа
- Подписывать запросы HMAC (заголовки `X-Timestamp`, `X-Signature`).
- Принцип наименьших привилегий для сервисных аккаунтов.
- Валидация входных данных (защита от инъекций).
- Лимитирование частоты запросов, idempotency по `X-Request-Id`.

## 4. Логи, метрики, наблюдаемость
- Структурированные логи (`requestId`, `sessionId`, команда, результат).
- Метрики: количество запросов, p95 latency, error rate.
- Health-эндпоинт и `/metrics` для мониторинга.

## 5. Документация и тесты
- README для `cloud/`: переменные, структура запроса/ответа, лимиты.
- Юнит-тесты парсеров и формирования payload.
- Интеграционные тесты в CI перед деплоем.

## 6. Оптимизация cold-starts
- Прогрев функции (cron-пинг раз в минуту).
- Минимум зависимостей и достаточный memory-quota.

## 7. Разграничение ответственности
- Вынести обработку навыка и отправку на ПК в разные функции (разные таймауты, права).
- Добавить e2e-скрипт для проверки связки «облако → ПК».

## 8. Автоматизация деплоя
- Скрипт сборки и деплоя (`npm run deploy:cloud`).
- Интеграция с GitHub Actions: деплой при мерже в `update-branch`.

# UX и удобство для пользователя

## 9. Персонализация и тон
- Определить «личность» навыка (дружелюбный или строгий тон).
- Ответы короткие и естественные (≤ 1–2 фраз).

## 10. Контекст и память
- Запоминать последнюю команду и окно в рамках сессии.
- Поддержка «повтори», «сделай то же самое».

## 11. Подтверждения и уточнения
- Для опасных команд («выключи ПК») спрашивать подтверждение.
- При неясности уточнять («Вы имели в виду …?»).

## 12. Естественный язык
- Поддержка синонимов, разговорных форм, чисел («громкость 70»).
- Локализация ответов (RU, EN).

## 13. Обратная связь и статус
- Голосовые и визуальные уведомления об успехе/ошибке.
- Иконка в трее: индикатор онлайна/офлайна, журнал команд.
- Сбор обратной связи («было полезно/нет») для улучшений.

## 14. Прозрачность и доверие
- Сообщать, что данные обрабатываются локально и не передаются третьим лицам.
- Публиковать политику конфиденциальности в README.

## 15. Расширение сценариев
- Пользовательские макрокоманды («рабочий режим»).
- Возможность управлять набором команд через конфиг.
